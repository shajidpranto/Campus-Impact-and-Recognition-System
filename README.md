
# Campus Impact & Recognition System

A C-based management system for managing campus contributions, working hours, points, and recognition.

## Features

- Add, edit, delete, and search contributors
- Track contribution hours
- Calculate points
- Leaderboard system
- Certificate eligibility tracking
- Check-in and check-out time tracking
- File-based data storage

## Technologies

- C
- Structures
- Functions
- Arrays
- Pointers
- Strings
- File Handling
